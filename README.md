# UPBGE Game Development — Persian Book

A practical, beginner-friendly Persian book for learning **UPBGE**, **Blender**, and real-time game development from the ground up.

This book is designed for readers who may have little or no previous experience with Blender, game engines, or Python. It starts with the UPBGE interface and gradually moves toward gameplay systems, scripting, physics, artificial intelligence, user interfaces, optimization, and building complete games.

> **Language:** Persian (Farsi)  
> **Format:** PDF / DOCX  
> **Focus:** UPBGE, Blender, Python, Game Development

---

## About the Book

UPBGE is a real-time game engine based on Blender. Because it is deeply integrated with Blender, it provides a complete workflow for creating assets, building scenes, scripting gameplay, designing materials, animating characters, and running interactive 3D applications inside a familiar environment.

The goal of this book is not simply to describe buttons and menus.

The book focuses on understanding:

- how UPBGE works,
- why different systems behave the way they do,
- how the different parts of a game communicate,
- how to debug problems,
- and how to structure a real project so it remains understandable as it grows.

Most concepts are introduced through practical examples and game-development scenarios instead of isolated definitions.

## Book Structure

The book is organized as a progressive learning path.

It begins with the fundamentals of the UPBGE and Blender environment, then moves into game logic, scripting, physics, and larger gameplay systems.

The later chapters focus on architecture, debugging, optimization, publishing, and complete projects.

Rather than treating every subject as an isolated lesson, the chapters are written as connected technical discussions so that concepts introduced earlier are reused in more advanced systems.

This book is suitable for:

## Python in This Book

Python is introduced gradually and specifically in the context of game development.

The book covers concepts such as:

- Variables
- Data types
- Conditions
- Loops
- Functions
- Lists and dictionaries
- Classes and objects
- Modules
- Error handling

These concepts are then applied directly inside UPBGE to build gameplay systems.

The goal is not to turn the book into a general-purpose Python textbook, but to teach enough Python to understand and build real game logic.
